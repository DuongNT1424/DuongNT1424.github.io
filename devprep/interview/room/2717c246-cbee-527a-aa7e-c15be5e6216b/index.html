Explain the difference between @Component, @Service and @Repository in Spring.
@Component is the generic stereotype; @Service marks business logic and @Repository marks data access, which also enables exception translation for persistence errors.
How does a JWT-based authentication flow work, and where should the refresh token be stored?
The client logs in and receives a short-lived access token plus a refresh token. The access token goes in the Authorization header; the refresh token should live in an HttpOnly cookie so scripts cannot read it.
